# Where the exemplar snippets come from

Nothing here is read when the skill runs. The samples in this directory, plus the one in
`../references/examples.md`, quote the Go team's own test code verbatim, and this file is
where that claim can be checked without spending a token of the skill's context on it.

Snippets were taken from a Go 1.27 development tree in June 2026. All 22 samples were
re-verified on 2026-07-29 against tag `go1.27rc2`, commit
`075e9d41dc2f4842ae0050a11b7c576bba9284a4`: every line of every code block appears
verbatim in its source file, excluding the marked elisions.

Source files, each under `src/` in that tree, as named by the `source` attribute of the
`<sample>` elements that quote them:

- `archive/zip/reader_test.go`
- `bufio/example_test.go`
- `cmd/gofmt/gofmt_test.go`
- `cmd/gofmt/testdata/rewrite1.input`
- `database/sql/sql_test.go`
- `encoding/json/example_test.go`
- `go/parser/error_test.go`
- `go/parser/testdata/commas.src`
- `hash/maphash/maphash_test.go`
- `index/suffixarray/example_test.go`
- `io/io_test.go`
- `io/multi_test.go`
- `strings/example_test.go`
- `strings/strings_test.go`
- `testing/fstest/testfs.go`

The three `database/sql` samples depend on that package's suite having been rewritten
around `testing/synctest`, and on `synctest.Sleep`. Neither exists in Go 1.26 or earlier,
so those samples cannot be found in a released tree before 1.27.

To re-verify after a release, resolve the tag and compare each sample's code block against
`https://raw.githubusercontent.com/golang/go/<tag>/src/<source>`.
